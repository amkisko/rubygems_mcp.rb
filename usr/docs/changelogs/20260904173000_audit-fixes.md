## Effects

get_ruby_versions writes the full list to the 24 hour cache on miss, then applies limit, offset, and sort. A cold cache with limit 1 returns one row. Specs that stub that list clear the process cache so later VCR changelog examples do not reuse fake URLs.

get_ruby_version_github_changelog uses make_request with the GitHub Accept header, so it shares the 5MB size cap and crawler checks. Empty or invalid GitHub JSON raises CorruptedDataError. 404 still returns the not-found hash and is not cached.

get_latest_versions and the MCP tool reject more than 20 gem names before HTTP.

Lock pins: json 2.21.2, addressable 2.9.0, concurrent-ruby 1.3.8, rack 3.2.7, nokogiri 1.19.4. fast-mcp floor is 1.6. nokogiri floor is 1.19. dependency-audit.yml finds Gemfile.lock and *.gemfile.lock. Dependabot watches /gemfiles. README, badge, gemspec comment, and Unreleased CHANGELOG match Ruby 3.4, 0.1.4, and raised errors. spec/README.md documents the suite.

Validation with RBENV_VERSION=3.4.10: bundle exec rspec spec/rubygems_mcp, 222 examples, 0 failures. make lint, no RuboCop offenses, rbs validate succeeded. bundle-audit check --no-update on all three locks, no vulnerabilities found.
